# NotMyDebt

Helps domestic violence advocates in California triage coerced debt on a survivor's credit report.

- **Claude guesses, with evidence.** Upload a credit report PDF. Claude reads it and flags accounts that look
  coerced, quoting the evidence from the report and the survivor's history.
- **Code applies the law.** Plain code checks whether California's coerced debt law (Civ. Code §§ 1798.97.1–.6,
  SB 975) covers each debt. Claude never decides coverage and never writes legal text.
- **She decides.** The survivor confirms which debts she didn't agree to and gets next steps for each.

> Information to review with a domestic violence advocate or legal aid attorney. Not legal advice.

## Data

All data is synthetic: a fictional person, lenders, and credit bureaus, generated by `scripts/` with organizer
approval. One sample report uses a layout modeled on the structure of a TransUnion consumer report, under a
fictional bureau name. `data/ground_truth*.json` holds the correct answers for each sample.

## Run

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # add your Anthropic API key
streamlit run app.py
python eval.py            # scores the pipeline against both answer keys
```

**65/65 checks pass.**

Limitations:
- Uses each account's open date as when the debt was incurred. A card opened before July 1, 2023 may have charges
  after that date that the law covers. Check with your advocate.
- California only, and only one bureau report at a time.
- Forced `tool_choice` isn't supported on `claude-sonnet-5-5`, so the call uses a strict `record_accounts` tool
  with `tool_choice: auto` and raises an error if Claude doesn't call it.
